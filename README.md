# 월드 풋볼 히스토리 시뮬레이터

축구가 창설되는 1863년부터 전세계 리그, 클럽대항전, 국가대항전, 발롱도르와 같은 개인상 흐름을 한 시즌씩 살펴보는 브라우저 기반 시뮬레이터입니다.

## 실행 방법

별도 빌드 도구 없이 정적 파일만으로 실행됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열면 됩니다.

## 주요 기능

- 1863년부터 2026년까지 시즌 단위 진행
- 역사적 확장, 균형 확장, 대체역사 급성장 모드
- 시대별 축구 생태계 설명
- 전세계 리그, 클럽대항전, 국가대항전 결과 생성
- 1956년 이후 발롱도르, 1991년 이후 여자 개인상 시뮬레이션
- 활성 대회, 대표 클럽, 국가대표, 스타 수치와 대륙별 위상 그래프
- 최근 80개 시즌의 역사 로그
